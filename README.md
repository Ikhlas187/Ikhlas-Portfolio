# portfolio-frontend

Portfolio d'Ikhlas Agbeti. Vite + React 19 + TypeScript 6, Tailwind v4 + shadcn/ui, GSAP.

```
pnpm install
pnpm dev        # http://localhost:3000
pnpm build      # typecheck puis build dans build/
pnpm preview
```

Architecture et conventions : `.claude/CLAUDE.md` et `.claude/rules/`.
